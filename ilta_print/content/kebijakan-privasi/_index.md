ILTA PRINT menggunakan informasi pelanggan untuk memproses konsultasi, estimasi harga, produksi, pengiriman, dan layanan setelah order.

Informasi yang dapat diterima meliputi nama, nomor WhatsApp, alamat pengiriman, detail pesanan, file desain, referensi visual, dan catatan kebutuhan produksi.

File dan informasi pelanggan tidak digunakan untuk tujuan di luar layanan tanpa izin, kecuali diperlukan untuk komunikasi produksi, administrasi order, atau pengiriman.

Pelanggan dapat menghubungi ILTA PRINT melalui WhatsApp untuk memperbarui informasi order atau meminta klarifikasi terkait data yang pernah dikirim.
