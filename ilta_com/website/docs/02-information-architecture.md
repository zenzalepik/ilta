# Information Architecture

## Struktur Single Page

1. Header
   - Logo
   - Navigasi anchor: Layanan, Paket, Proses, Portofolio, FAQ
   - CTA WhatsApp

2. Hero
   - Headline: pembuatan website profesional untuk bisnis yang ingin tampil kredibel
   - Subcopy: fokus pada website, toko online, dan sistem ringan
   - CTA utama dan sekunder
   - Visual website preview
   - Trust metrics

3. Pain Points
   - Website lama tidak meyakinkan
   - Calon pelanggan susah mengerti layanan
   - Website lambat atau tidak mobile-friendly
   - Tim butuh alur kerja yang jelas

4. Layanan
   - Company profile
   - Landing page
   - Toko online
   - Website organisasi
   - Custom fitur
   - Maintenance dan optimasi

5. Paket Harga
   - Paket Pelajar
   - Paket Hemat
   - UMKM
   - Starter Website
   - Business Website
   - Commerce Website
   - Custom Build
   - Catatan integrasi sosial media hanya link/profil, bukan jasa marketing

6. Proses Kerja
   - Discovery
   - Struktur dan copy
   - Desain
   - Development
   - Review
   - Launch dan handover

7. Portofolio
   - Kartu studi kasus konseptual sebagai placeholder
   - Bidang: klinik, sekolah, toko, jasa profesional

8. Tech Stack
   - Tailwind CDN untuk prototype
   - HTML statis
   - Struktur siap dipindah ke framework jika dibutuhkan

9. FAQ
   - Lama pengerjaan
   - Materi dari klien
   - Domain dan hosting
   - Revisi
   - Maintenance
   - SEO dasar

10. Final CTA
    - Ajakan konsultasi
    - Link WhatsApp

11. Footer
    - Brand
    - Navigasi ringkas
    - Catatan fokus layanan

12. Blog/Artikel
    - 9 artikel ringkas
    - 6 artikel website, copywriting, marketing, selling, strategi, trust
    - 3 artikel aplikasi mobile dan bisnis
    - Menu header `Artikel` menuju `artikel.html`
    - Card artikel menuju `artikel-detail.html?slug=...`

## Halaman Lanjutan Yang Bisa Dibuat Nanti

- `/harga.html`
- `/portofolio.html`
- `/layanan/website-company-profile.html`
- `/layanan/toko-online.html`
- `/blog.html`
- `/kontak.html`

## Prinsip Navigasi

- Semua section utama bisa dicapai dari header.
- CTA WhatsApp selalu tersedia di desktop dan mobile.
- Pengunjung bisa memahami penawaran tanpa harus membuka halaman lain.
- Pricing dan FAQ ditempatkan sebelum CTA akhir untuk mengurangi keraguan.
