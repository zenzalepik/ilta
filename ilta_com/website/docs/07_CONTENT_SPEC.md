# Content Specification & Copywriting Guide

## 1. Tone of Voice
- **Professional yet Approachable:** Enterprise-grade credibility but not stiff.
- **Direct & Action-Oriented:** Use active verbs ("Mulai", "Kerjakan", "Hubungi").
- **Empathetic to Pain Points:** Acknowledge manual processes, vendor failures, scaling issues.
- **Indonesian Business Context:** Use terms like "SME", "Zero Komitmen", "SLA", "Go-Live".

## 2. Key Messaging Pillars
| Pillar | Message | Evidence |
|--------|---------|----------|
| **Gratis Prototype** | "Konsultasi gratis" is abstract. We deliver a real prototype. | "Dikerjakan langsung oleh SME BADR." |
| **Enterprise Trust** | 14+ years, ISO 27001, 100+ clients. | Logos: Pertamina, Astra, Kemenkeu, UNDP. |
| **Speed & Responsiveness** | 1-hour response time. | "Senin–Jumat 08.00–18.00 WIB." |
| **No Vendor Lock-in** | Scalable, maintainable, transferable code. | "Tanpa ketergantungan vendor jangka panjang." |

## 3. Page-by-Page Copy Structure

### Landing Page (Hero)
- **Headline:** "Jasa Pembuatan Kustom Software sesuai Proses Bisnis Anda."
- **Subhead:** "Prototype & Requirement Gathering Gratis. Dikerjakan langsung oleh Subject Matter Expert."
- **CTA Primary:** "Mulai Konsultasi Gratis"
- **CTA Secondary:** "Chat WhatsApp"
- **Trust Bar:** "Dipercaya Pertamina, Astra, Kemenkeu, dan 100+ klien enterprise."

### Pain Points Section
- "Apakah perusahaan Anda menghadapi salah satu dari ini?"
- 4 Cards: Manual Process, Legacy Scaling, Bad Vendor, Data Silos.

### Services Section
- 6 Cards: Custom ERP, CRM/HRIS, Web Apps, API Integration, QA Testing, Maintenance.
- Each card: Icon + Title + 1-sentence benefit.

### Portfolio Section
- Case Study Cards: Title, Client, 3 Key Metrics (e.g., "11.976 Fasilitas", "Error -95%").

### FAQ Section
- 6 Questions covering: Free prototype authenticity, who handles it, pricing, timeline, differentiation.
